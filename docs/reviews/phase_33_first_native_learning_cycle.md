# Phase 33: first native AlphaZero learning cycle

## Objective

The project now pauses component tuning. The only question is whether one
complete native 5x5 cycle can improve the selected pretrained agent:

`generation 0 -> neural self-play -> replay training -> generation 1 -> Elo`

Generation 2 is not authorized until generation 1 has fresh games against its
parent and the two fixed anchors.

## Frozen inputs

- Parent: 32x3 soft-Z epoch 84, SHA-256
  `3bc3ca17393ce803d3d89ccc02f649cfb755b56b1af944c1f41c82db4114beb6`.
- Neural self-play: reuse the audited noise-off arm of job 33604. It contains
  256 games and 3,269 positions generated by the parent with 32 simulations,
  `c_puct=1.5`, parent-Q FPU, visit sampling through ply 4, and no root noise.
- Rollout anchor: the audited 512-game, 6,838-position tactical-rollout corpus.
- Network and search remain native 5x5/75 and absolute Player-1 valued.

Reusing the valid job-33604 games avoids paying for identical self-play merely
because their first use was diagnostic.

## Training contract

Split each source independently by complete game. Every immutable position is
read, but source loss weights make rollout pretraining contribute 75% and
neural self-play 25% in both training and validation. This is an explicit
anti-forgetting curriculum, not duplication of files or oversampling disguised
as new evidence.

Fine-tune the parent for 120 seconds with Adam at `3e-4`, batch size 256, the
balanced four-epoch symmetry cycle, and checkpoints every four epochs. Use the
fixed `0.5 * outcome + 0.5 * root-Q` target: the outcome component prevents the
online value head from learning only its own bootstrapped opinion. Select the
saved checkpoint with minimum weighted validation total. No target,
architecture, optimizer, replay ratio, or search sweep accompanies this run.

## Evaluation and decision

On 64 new four-ply opening pairs, play generation 0 and generation 1 against
each other, alpha-beta, and tactical-rollout PUCT. Reverse colors for every
opening. Search receives 50 ms per move, with 100 ms of scheduler-classification
grace; search noise and symmetry averaging are off.

- Any abnormal game invalidates the arena.
- If generation 1 is clearly worse than its parent, stop. Diagnose replay
  balance, optimizer displacement, policy entropy, value calibration, and
  simulations completed; do not generate more games.
- If the parent interval overlaps zero, also inspect both fixed anchors. A
  useful generation should at least hold its parent while narrowing one anchor
  gap without materially widening the other.
- Only a non-regressing result authorizes generation 2. This first run is one
  learning seed, so it establishes pipeline direction rather than a general
  replay-ratio or value-target conclusion.
